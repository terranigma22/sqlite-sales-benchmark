Metodología

5 pasadas de 1,000,000 ventas cada una, con la misma configuración. Warm-up de 100,000 ventas antes de cada pasada; cada pasada resetea la base. La API se mantiene caliente entre pasadas. La media es aritmética; la mediana se incluye para ver la dispersión. No se generaron CSV ni informes individuales.
